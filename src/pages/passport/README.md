# 岛民护照

首页仅展示封皮，点击进入独立 `/#/passport` 阅读页。

## 页序与交互

封面 → 左侧封面背面 / 右侧资料页（1–2）→ 签证（第 3 页起）→ 世界地图 → 中国地图 → 左侧旅行年鉴 / 右侧封底背面 → 封底。

签证每页最多 6 枚，按实际数量分页；不足偶数页时补空白签证页。地图各占一个完整跨页，旅行年鉴位于倒数第二张内页（左页），最后的右页是封底背面，页码随签证数量自动计算。资料与签证是独立的章节入口。

- 桌面为双页护照，封面在右，封底合在左侧。资料页的机器可读编码朝右侧外缘；资料与年鉴内容均逆时针摆放 90°，点击后整本护照顺时针旋转以横向阅读，工具栏可转回。
- 资料与年鉴复用原来的 760 × 499 横向版式并铺满页面。资料页的亚克力层贴齐外缘，靠书脊保留 30px 纸质装订区及纸页弧度；手机横向页面保留顶部 10px 纸边。年鉴直接使用纸页背景，没有内嵌卡片边框。封皮使用细颗粒皮革纹理和压印文字。
- 签证页只保留居中的 VISA 标题。移除独立的小号页码，页码水印与 WCI 编码按书页奇偶数靠外侧下角排列。
- 内页使用曲线轮廓，书脊上下内收；移除跨页外框与封皮浅色纸边。翻页正反面和阴影均按实际封皮 / 纸页轮廓裁切。
- 700px 及以下为单页。左右轻扫或点击箭头切页，动画使用水平滑屏；地图作为完整地图显示，城市记录放在下面。
- 章节导航与键盘左右箭头均可翻页；地图内方向键留给放大镜。减少动态效果偏好下直接切页。
- 翻页期间锁定导航。动画的静态底层只保留对应半页，封面和封底不会额外留下整页残影；隐藏页面及动画副本不可聚焦。
- 地图首次访问才加载；翻回地图保留地点选择、放大镜和索引状态。城市文章入口和签证章均链接现有旅行文章，没有文章时显示“游记待记录”。

## 文件

- `page.tsx`：原版资料、年鉴、签证，以及完整页序。
- `PassportBook.tsx`：封皮、章节、旋转、单 / 双页切换、动画和手势。
- `book.css`：装帧、皮革与亚克力材质、动画和响应式布局。
- `styles.css`：资料、年鉴和共享旅行章原始样式；护照尺寸覆盖限定在 `.passport-reader`。
- `passport.data.ts`、`travel-stamps.data.ts`：护照编码、章数、旅行数据与文章匹配。
- `journey-map/`：世界 / 中国地图、省份与国家分组、可拖动放大镜及城市记录。
